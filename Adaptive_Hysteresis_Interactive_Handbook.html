Core question

When is a movement large and persistent enough to count as a real state change rather than ordinary oscillation?

Input

A continuous score such as percentage distance from an MA, position inside a Donchian channel, RSI reversion pressure, or relative volatility.

Filter

Two thresholds and memory. The state changes only at the outer thresholds and remains unchanged inside the band.

Output

A stable state such as bullish/bearish, long/flat, high/low volatility, or breakout/no breakout.

What success means

  • Fewer rapid back-and-forth changes.
  • Confirmed transitions are more likely to continue for the chosen horizon.
  • The filter still produces enough events to be useful.
  • The improvement survives chronological out-of-sample testing and realistic costs.
No universal threshold exists. A threshold is conditional on the signal scale, instrument, timeframe, market regime, costs, and your definition of a false signal.

Interactive Schmitt-trigger variant laboratory

In electronics, a true Schmitt trigger switches at a higher point while the input rises and at a lower point while it falls. For trading, the input should usually be a derived score—such as price distance from MA48—not the absolute price level. The gap between the two switching levels rejects ordinary oscillation while the state memory prevents immediate reversal inside the band.

Small threshold

Large threshold

The state rule

Switch to +1 when score ≥ upper. Switch to −1 when score ≤ lower. Otherwise keep the previous state.
Python
def schmitt_state(
    score: pd.Series,
    upper: Real | pd.Series,
    lower: Real | pd.Series,
    confirmation_bars: int = 1,
    initial_state: int = 0,
) -> pd.Series:
    """Convert a noisy score into stable -1/0/+1 states.

    The state switches upward only after the score reaches ``upper`` and
    switches downward only after the score reaches ``lower``. Between the two
    thresholds, the previous state is retained.
    """
    if confirmation_bars < 1:
        raise ValueError("confirmation_bars must be at least 1.")
    if initial_state not in {-1, 0, 1}:
        raise ValueError("initial_state must be -1, 0, or 1.")

    upper_array = _as_array(upper, score.index, "upper")
    lower_array = _as_array(lower, score.index, "lower")
    states = _schmitt_array(
        score.to_numpy(dtype=np.float64),
        upper_array,
        lower_array,
        int(confirmation_bars),
        int(initial_state),
    )
    return pd.Series(states, index=score.index, name="schmitt_state")
The memory is essential. A pair of threshold comparisons without retaining the previous state is a band classifier, not a Schmitt trigger.

Design the research question before optimizing

Optimization is only meaningful after you define exactly what counts as an oscillation, a continuation, and an acceptable number of signals.

Interactive event-definition laboratory

Change the evaluation horizon and quick-reversal window. The same transitions are reclassified immediately.

Recommended event definition

  1. A transition event occurs when the filtered state changes.
  2. A quick reversal occurs when the state changes back within a chosen number of bars.
  3. A continuation occurs when the direction-adjusted future return is above a chosen minimum after a fixed horizon.
  4. A useful configuration must produce at least a minimum number of events.

Example horizon

On 5-minute data, 12 bars means one hour. Choose it from the intended decision horizon, not after seeing the best result.

Example reversal window

Six bars means a state that reverses within 30 minutes is treated as unstable.

Minimum move

Zero tests direction only. A positive minimum move can require continuation large enough to matter after costs.

What the downloader guarantees

  • UTC-aware timestamps.
  • Only candles whose opening time is before the current still-open candle.
  • Forward pagination with a stop condition that prevents an infinite repeated-page loop.
  • No invented rows when the exchange returns less history than requested.
  • An explicit failure if the symbol or OHLCV capability is unavailable.
Python
def fetch_ohlcv_paginated(
    exchange: ccxt.Exchange,
    symbol: str,
    timeframe: str,
    start: str | pd.Timestamp,
    end: str | pd.Timestamp | None = None,
    limit_candidates: Iterable[int] = (1_000, 500, 200, 100),
    max_retries: int = 5,
) -> pd.DataFrame:
    """Download closed OHLCV candles with forward pagination.

    The function starts with a large request limit and falls back to smaller
    limits if an exchange rejects it. It never fabricates missing candles.
    """
    if symbol not in exchange.markets:
        raise ValueError(f"Symbol {symbol!r} is not available on {exchange.id}.")

    timeframe_ms = timeframe_to_milliseconds(timeframe)
    start_ms = int(_to_utc_timestamp(start).timestamp() * 1_000)

    now_ms = exchange.milliseconds()
    current_candle_open_ms = now_ms - (now_ms % timeframe_ms)
    requested_end_ms = (
        int(_to_utc_timestamp(end).timestamp() * 1_000)
        if end is not None
        else current_candle_open_ms
    )
    end_ms = min(requested_end_ms, current_candle_open_ms)

    if start_ms >= end_ms:
        raise ValueError("The start time must be earlier than the last closed candle.")

    limits = tuple(int(value) for value in limit_candidates)
    if not limits or any(value <= 0 for value in limits):
        raise ValueError("limit_candidates must contain positive integers.")

    rows: list[list[float]] = []
    since_ms = start_ms
    previous_last_timestamp: int | None = None
    active_limit_index = 0

    while since_ms < end_ms:
        batch: list[list[float]] | None = None
        last_error: Exception | None = None

        while active_limit_index < len(limits) and batch is None:
            limit = limits[active_limit_index]

            for attempt in range(max_retries):
                try:
                    batch = exchange.fetch_ohlcv(
                        symbol=symbol,
                        timeframe=timeframe,
                        since=since_ms,
                        limit=limit,
                    )
                    break
                except (
                    ccxt.NetworkError,
                    ccxt.RequestTimeout,
                    ccxt.DDoSProtection,
                    ccxt.RateLimitExceeded,
                ) as exc:
                    last_error = exc
                    time.sleep(min(2**attempt, 30))
                except ccxt.ExchangeError as exc:
                    last_error = exc
                    break

            if batch is None:
                active_limit_index += 1

        if batch is None:
            raise RuntimeError(
                "OHLCV download failed for every request limit. "
                f"Last error: {last_error}"
            )

        if len(batch) == 0:
            break

        filtered_batch = [
            row for row in batch if start_ms <= int(row[0]) < end_ms
        ]
        rows.extend(filtered_batch)

        last_timestamp = int(batch[-1][0])
        if previous_last_timestamp is not None and last_timestamp <= previous_last_timestamp:
            break

        previous_last_timestamp = last_timestamp
        since_ms = last_timestamp + timeframe_ms

        if len(batch) < limits[active_limit_index]:
            break

    frame = pd.DataFrame(rows, columns=OHLCV_COLUMNS)
    if frame.empty:
        raise RuntimeError(
            "The exchange returned no candles for the requested symbol and period."
        )

    frame["timestamp"] = pd.to_datetime(frame["timestamp"], unit="ms", utc=True)
    frame = frame.set_index("timestamp")
    numeric_columns = ["open", "high", "low", "close", "volume"]
    frame[numeric_columns] = frame[numeric_columns].apply(
        pd.to_numeric,
        errors="coerce",
    )
    return frame
Do not assume 730 days were received. Print the real first timestamp, last timestamp and row count. A request limit is not the same as historical availability.

def validate_ohlcv(
    frame: pd.DataFrame,
    timeframe: str,
    remove_incomplete_last_candle: bool = True,
) -> tuple[pd.DataFrame, ValidationReport]:
    """Validate and sort OHLCV data without silently filling gaps."""
    required = {"open", "high", "low", "close", "volume"}
    missing_columns = required.difference(frame.columns)
    if missing_columns:
        raise ValueError(f"Missing OHLCV columns: {sorted(missing_columns)}")
    if not isinstance(frame.index, pd.DatetimeIndex):
        raise TypeError("The DataFrame index must be a DatetimeIndex.")

    data = frame.copy()
    if data.index.tz is None:
        data.index = data.index.tz_localize("UTC")
    else:
        data.index = data.index.tz_convert("UTC")

    original_index_ns = data.index.asi8
    out_of_order_rows = int((original_index_ns[1:] < original_index_ns[:-1]).sum())
    duplicate_timestamps = int(data.index.duplicated(keep=False).sum())

    data = data.sort_index(kind="stable")
    data = data[~data.index.duplicated(keep="last")]

    timeframe_ms = timeframe_to_milliseconds(timeframe)
    incomplete_removed = False
    if remove_incomplete_last_candle and not data.empty:
        now_ms = int(pd.Timestamp.now(tz="UTC").timestamp() * 1_000)
        last_open_ms = int(data.index[-1].timestamp() * 1_000)
        if last_open_ms + timeframe_ms > now_ms:
            data = data.iloc[:-1]
            incomplete_removed = True

    numeric_columns = ["open", "high", "low", "close", "volume"]
    data[numeric_columns] = data[numeric_columns].apply(
        pd.to_numeric,
        errors="coerce",
    )

    price_columns = ["open", "high", "low", "close"]
    non_positive_prices = int((data[price_columns] <= 0).any(axis=1).sum())
    negative_volume_rows = int((data["volume"] < 0).sum())
    missing_numeric_rows = int(data[numeric_columns].isna().any(axis=1).sum())

    row_max = data[["open", "low", "close"]].max(axis=1)
    row_min = data[["open", "high", "close"]].min(axis=1)
    invalid_ohlc = (data["high"] < row_max) | (data["low"] > row_min)
    invalid_ohlc_rows = int(invalid_ohlc.sum())

    timestamp_ms = data.index.asi8 // 1_000_000
    if len(timestamp_ms) > 1:
        gaps = (timestamp_ms[1:] - timestamp_ms[:-1]) // timeframe_ms - 1
        missing_intervals = int(gaps[gaps > 0].sum())
    else:
        missing_intervals = 0

    report = ValidationReport(
        rows=len(data),
        duplicate_timestamps=duplicate_timestamps,
        out_of_order_rows=out_of_order_rows,
        missing_intervals=missing_intervals,
        non_positive_prices=non_positive_prices,
        negative_volume_rows=negative_volume_rows,
        missing_numeric_rows=missing_numeric_rows,
        invalid_ohlc_rows=invalid_ohlc_rows,
        incomplete_last_candle_removed=incomplete_removed,
    )
    return data, report
Why use the longest contiguous segment? Chronological folds should cover comparable durations. Row-based splitting on a series with large time gaps can create misleading fold comparisons. Excluded gaps still need investigation; selecting a segment is not a repair.
Chapter 7

The signal contract

A reusable hysteresis engine should not know whether its input came from an MA, RSI, a channel, volatility or a model. Every strategy first produces a continuous score.

Interactive signal-contract transformer

Choose a score family and normalization. A good contract puts different signals into a documented, comparable scale before hysteresis.

A good score has four properties

Directional meaning

Larger values consistently mean more evidence for one state; smaller values mean more evidence for the opposite state.

Causal construction

The value at time t uses only information available by time t.

Understandable scale

Percentage, ATR units, standard-deviation units or a bounded oscillator make threshold ranges interpretable.

Enough variation

A nearly constant or extremely sparse score gains little from hysteresis.

Generic interface

When hysteresis is unsuitable

  • The strategy already emits rare discrete events rather than a noisy continuous measurement.
  • A delayed state change is unacceptable for the use case.
  • The score meaning changes over time and is not normalized.
  • The threshold is optimized on the same period used for the final performance claim.

def ma_distance_score(close: pd.Series, window: int) -> pd.Series:
    """Return percentage distance between price and a trailing simple MA."""
    if window < 2:
        raise ValueError("window must be at least 2.")
    moving_average = close.rolling(window=window, min_periods=window).mean()
    score = close.div(moving_average).sub(1.0)
    return score.rename(f"ma_distance_{window}")

Why not mix the four strategies immediately?

Combining them before understanding each one hides which scale creates the noise, which threshold is stable, and whether one signal dominates. First create a result table per MA; build a multi-scale ensemble only after independent out-of-sample evidence exists.

Non-MA strategies suitable for hysteresis

Hysteresis is most useful around any threshold that a noisy score repeatedly crosses. These alternatives differ materially from a price-versus-MA crossover.

Interactive non-MA strategy laboratory

The same hysteresis state machine can sit behind very different causal scores. Select a family to see its natural thresholds.

1. Donchian channel breakout

The channel is based on prior rolling highs and lows. A normalized score above +1 means price closed above the previous upper channel; below −1 means it closed below the previous lower channel. The current candle is excluded with shift(1), so it cannot define the level it is supposedly breaking.

Python
def donchian_position_score(frame: pd.DataFrame, window: int = 48) -> pd.Series:
    """Position price inside the prior Donchian range.

    A score above +1 means the close is above the previous channel high.
    A score below -1 means it is below the previous channel low. The channel
    uses ``shift(1)`` so the current candle cannot define its own threshold.
    """
    if window < 2:
        raise ValueError("window must be at least 2.")

    upper = frame["high"].shift(1).rolling(window, min_periods=window).max()
    lower = frame["low"].shift(1).rolling(window, min_periods=window).min()
    midpoint = (upper + lower) / 2
    half_range = (upper - lower) / 2
    score = (frame["close"] - midpoint).div(half_range.replace(0, np.nan))
    return score.rename(f"donchian_position_{window}")

Use: long/short trend state, breakout confirmation, or a gate for another strategy.

2. RSI mean-reversion pressure

Map RSI into a score where oversold conditions are positive and overbought conditions are negative. A symmetric long/short state can use upper and lower thresholds; a long/flat implementation uses a higher entry threshold and a lower exit threshold.

Python
def rsi_reversion_score(close: pd.Series, period: int = 14) -> pd.Series:
    """Create a mean-reversion preference score from RSI.

    Positive values represent an oversold/long preference; negative values
    represent an overbought/short preference. The result lies roughly in
    [-1, +1].
    """
    indicator = rsi(close, period=period)
    return ((50.0 - indicator) / 50.0).rename(f"rsi_reversion_{period}")

3. Realized-volatility regime

This is not inherently a directional trade. It classifies whether recent volatility is high or low relative to its own historical baseline. The state can change position size, select a strategy, or suspend trading.

Python
def volatility_regime_score(
    close: pd.Series,
    short_window: int = 48,
    baseline_window: int = 1_440,
) -> pd.Series:
    """Compare recent realized volatility with its past rolling median."""
    if short_window < 5 or baseline_window <= short_window:
        raise ValueError("Use short_window >= 5 and baseline_window > short_window.")

    log_return = np.log(close).diff()
    recent_volatility = log_return.rolling(
        short_window,
        min_periods=short_window,
    ).std(ddof=0)
    historical_baseline = (
        recent_volatility.shift(1)
        .rolling(baseline_window, min_periods=baseline_window)
        .median()
    )
    score = recent_volatility.div(historical_baseline.replace(0, np.nan)).sub(1.0)
    return score.rename(f"volatility_regime_{short_window}_{baseline_window}")

Further suitable families

CUSUM change evidence

Accumulate standardized positive and negative returns until evidence exceeds a threshold. Hysteresis can stabilize the detected direction.

Volume-pressure score

Combine signed return with relative volume, then require stronger evidence to enter than to leave a state.

Model probability

Enter a positive state only above a high probability and leave it below a lower probability. Calibration quality becomes critical.

Order-book imbalance

Useful at shorter horizons, but requires high-quality order-book data and careful synchronization; OHLCV alone is insufficient.

Best first non-MA candidate: Donchian breakout. Its thresholds have a clear market meaning, the score can be causal, and it naturally suffers from false breakouts that hysteresis is designed to reduce.

Bounded single-objective score

The supplied starter uses a transparent weighted score and a hard minimum-event constraint:

0.45 × continuation + 0.35 × (1 − false reversal) + 0.20 × noise reduction
Python
def bounded_quality_score(
    quality: SignalQuality,
    minimum_events: int,
    maximum_flip_rate_per_1_000: float | None = None,
) -> float:
    """Combine interpretable signal metrics into a bounded Optuna score.

    Hard event-count and optional turnover constraints prevent the optimizer
    from selecting a threshold that simply produces no signals.
    """
    if quality.events < minimum_events:
        shortage = (minimum_events - quality.events) / max(minimum_events, 1)
        return -1.0 - shortage

    if (
        maximum_flip_rate_per_1_000 is not None
        and quality.flip_rate_per_1_000 > maximum_flip_rate_per_1_000
    ):
        excess = (
            quality.flip_rate_per_1_000 / maximum_flip_rate_per_1_000 - 1.0
        )
        return -0.5 - excess

    values = [
        quality.continuation_hit_rate,
        1.0 - quality.false_reversal_rate,
        quality.noise_reduction,
    ]
    if not all(np.isfinite(value) for value in values):
        return -2.0

    return float(
        0.45 * quality.continuation_hit_rate
        + 0.35 * (1.0 - quality.false_reversal_rate)
        + 0.20 * quality.noise_reduction
    )
The weights express a research preference, not a law. Run sensitivity analysis. A candidate that wins only for one narrow weight choice is weak evidence.

When to use multi-objective Optuna

Later, return separate objectives such as minimizing false reversals and maximizing continuation. Inspect the Pareto front instead of forcing one weight combination. Keep event count and extreme turnover as constraints. Too many objectives make the Pareto set difficult to interpret, so start with two or three.

    filtered_state: pd.Series,
    close: pd.Series,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_move: float = 0.0,
) -> SignalQuality:
    """Evaluate whether filtered transitions are stable and continue.

    Future returns are used only for evaluation. They must never be used to
    construct the score or thresholds.
    """
    if horizon < 1 or reversal_window < 1:
        raise ValueError("horizon and reversal_window must be positive.")

    common_index = score.index.intersection(filtered_state.index).intersection(close.index)
    score_aligned = score.reindex(common_index)
    state_aligned = filtered_state.reindex(common_index).fillna(0).astype(np.int8)
    close_aligned = close.reindex(common_index).astype(float)

    from .triggers import raw_sign_state

    raw_state = raw_sign_state(score_aligned)
    raw_flips = count_flips(raw_state)
    filtered_flips = count_flips(state_aligned)
    events = transition_positions(state_aligned)

    future_return = close_aligned.shift(-horizon).div(close_aligned).sub(1.0)
    valid_events = events[events + horizon < len(close_aligned)]

    if valid_events.size:
        directions = state_aligned.iloc[valid_events].to_numpy(dtype=float)
        signed_returns = directions * future_return.iloc[valid_events].to_numpy(dtype=float)
        finite = np.isfinite(signed_returns)
        signed_returns = signed_returns[finite]
    else:
        signed_returns = np.array([], dtype=float)

    continuation_hit_rate = (
        float(np.mean(signed_returns > minimum_move))
        if signed_returns.size
        else float("nan")
    )
    median_signed_return = (
        float(np.median(signed_returns)) if signed_returns.size else float("nan")
    )

    state_values = state_aligned.to_numpy(dtype=np.int8)
    false_reversals = 0
    reversal_candidates = 0
    for position in events:
        end = min(position + reversal_window + 1, len(state_values))
        if end <= position + 1:
            continue
        reversal_candidates += 1
        direction = state_values[position]
        if np.any((state_values[position + 1 : end] != direction) & (state_values[position + 1 : end] != 0)):
            false_reversals += 1

    false_reversal_rate = (
        false_reversals / reversal_candidates
        if reversal_candidates
        else float("nan")
    )

    lengths = run_lengths(state_aligned)
    median_run_length = float(np.median(lengths)) if lengths.size else float("nan")
    noise_reduction = (
        1.0 - filtered_flips / raw_flips if raw_flips > 0 else 0.0
    )
    flip_rate = 1_000.0 * filtered_flips / max(len(state_aligned), 1)

    return SignalQuality(
        observations=len(state_aligned),
        events=int(events.size),
        raw_flips=raw_flips,
        filtered_flips=filtered_flips,
        flip_rate_per_1_000=float(flip_rate),
        noise_reduction=float(noise_reduction),
        continuation_hit_rate=continuation_hit_rate,
        median_signed_forward_return=median_signed_return,
        false_reversal_rate=float(false_reversal_rate),
        median_run_length=median_run_length,
    )

def optimize_threshold(
    score: pd.Series,
    close: pd.Series,
    n_trials: int = 80,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_events: int = 20,
    asymmetric: bool = True,
    optimize_confirmation: bool = True,
    inner_splits: int = 3,
    seed: int = 42,
) -> optuna.Study:
    """Optimize thresholds across chronological inner validation folds."""
    index = score.index.intersection(close.index)
    score_aligned = score.reindex(index)
    close_aligned = close.reindex(index)
    valid = score_aligned.notna() & close_aligned.notna()
    score_aligned = score_aligned[valid]
    close_aligned = close_aligned[valid]

    if len(score_aligned) < 500:
        raise ValueError("At least 500 valid rows are recommended for optimization.")

    low, high = _search_bounds(score_aligned)
    splitter = TimeSeriesSplit(n_splits=inner_splits)
    sampler = optuna.samplers.TPESampler(seed=seed)
    study = optuna.create_study(direction="maximize", sampler=sampler)

    def objective(trial: optuna.Trial) -> float:
        upper = trial.suggest_float("upper", low, high, log=True)
        lower_abs = (
            trial.suggest_float("lower_abs", low, high, log=True)
            if asymmetric
            else upper
        )
        confirmation_bars = (
            trial.suggest_int("confirmation_bars", 1, 8)
            if optimize_confirmation
            else 1
        )

        fold_scores: list[float] = []
        for _, validation_positions in splitter.split(score_aligned):
            validation_start = int(validation_positions[0])
            validation_end = int(validation_positions[-1]) + 1

            # Generate state on all data available up to the validation end.
            # This preserves causal state memory at the validation boundary.
            score_context = score_aligned.iloc[:validation_end]
            state_context = schmitt_state(
                score_context,
                upper=upper,
                lower=-lower_abs,
                confirmation_bars=confirmation_bars,
            )

            validation_slice = slice(validation_start, validation_end)
            quality = evaluate_signal_quality(
                score=score_context.iloc[validation_slice],
                filtered_state=state_context.iloc[validation_slice],
                close=close_aligned.iloc[validation_slice],
                horizon=horizon,
                reversal_window=reversal_window,
            )
            fold_scores.append(
                bounded_quality_score(
                    quality,
                    minimum_events=max(3, minimum_events // inner_splits),
                )
            )

        return float(np.mean(fold_scores))

    study.optimize(objective, n_trials=n_trials)
    return study

def walk_forward_optimize(
    score: pd.Series,
    close: pd.Series,
    outer_splits: int = 5,
    n_trials: int = 60,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_events: int = 20,
    asymmetric: bool = True,
    optimize_confirmation: bool = True,
    seed: int = 42,
) -> tuple[pd.DataFrame, pd.Series]:
    """Tune on past data and evaluate each selected threshold on unseen data."""
    index = score.index.intersection(close.index)
    score_aligned = score.reindex(index)
    close_aligned = close.reindex(index)
    valid = score_aligned.notna() & close_aligned.notna()
    score_aligned = score_aligned[valid]
    close_aligned = close_aligned[valid]

    splitter = TimeSeriesSplit(n_splits=outer_splits)
    out_of_sample_state = pd.Series(
        np.zeros(len(score_aligned), dtype=np.int8),
        index=score_aligned.index,
        name="walk_forward_state",
    )
    fold_results: list[FoldResult] = []

    for fold, (train_positions, test_positions) in enumerate(
        splitter.split(score_aligned),
        start=1,
    ):
        train_end = int(train_positions[-1]) + 1
        test_start = int(test_positions[0])
        test_end = int(test_positions[-1]) + 1

        study = optimize_threshold(
            score=score_aligned.iloc[:train_end],
            close=close_aligned.iloc[:train_end],
            n_trials=n_trials,
            horizon=horizon,
            reversal_window=reversal_window,
            minimum_events=minimum_events,
            asymmetric=asymmetric,
            optimize_confirmation=optimize_confirmation,
            seed=seed + fold,
        )

        params = study.best_params
        upper = float(params["upper"])
        lower_abs = float(params.get("lower_abs", upper))
        confirmation_bars = int(params.get("confirmation_bars", 1))

        # Generate state from the beginning through the test fold so the test
        # state depends only on past observations and keeps boundary memory.
        context_score = score_aligned.iloc[:test_end]
        context_state = schmitt_state(
            context_score,
            upper=upper,
            lower=-lower_abs,
            confirmation_bars=confirmation_bars,
        )
        test_state = context_state.iloc[test_start:test_end]
        out_of_sample_state.iloc[test_start:test_end] = test_state.to_numpy()

        test_quality = evaluate_signal_quality(
            score=score_aligned.iloc[test_start:test_end],
            filtered_state=test_state,
            close=close_aligned.iloc[test_start:test_end],
            horizon=horizon,
            reversal_window=reversal_window,
        )

        fold_results.append(
            FoldResult(
                fold=fold,
                test_start=score_aligned.index[test_start],
                test_end=score_aligned.index[test_end - 1],
                upper=upper,
                lower=-lower_abs,
                confirmation_bars=confirmation_bars,
                objective_value=float(study.best_value),
                test_events=test_quality.events,
                test_continuation_hit_rate=test_quality.continuation_hit_rate,
                test_false_reversal_rate=test_quality.false_reversal_rate,
                test_noise_reduction=test_quality.noise_reduction,
            )
        )

    results_frame = pd.DataFrame(result.to_dict() for result in fold_results)
    return results_frame, out_of_sample_state

def backtest_state(
    close: pd.Series,
    state: pd.Series,
    cost_bps_per_unit_turnover: float = 5.0,
    periods_per_year: int = 365 * 24 * 12,
) -> tuple[pd.DataFrame, BacktestResult]:
    """Evaluate a state using next-bar returns and linear trading costs.

    The position is lagged by one bar. This prevents a signal calculated from
    a candle close from earning the return that ended at that same close.
    This is a research approximation, not an execution simulator.
    """
    if cost_bps_per_unit_turnover < 0:
        raise ValueError("Trading cost cannot be negative.")
    if periods_per_year <= 0:
        raise ValueError("periods_per_year must be positive.")

    index = close.index.intersection(state.index)
    close_aligned = close.reindex(index).astype(float)
    state_aligned = state.reindex(index).fillna(0).astype(float)

    market_return = close_aligned.pct_change().fillna(0.0)
    position = state_aligned.shift(1).fillna(0.0)
    turnover = position.diff().abs().fillna(position.abs())
    cost_rate = cost_bps_per_unit_turnover / 10_000.0

    gross_return = position * market_return
    net_return = gross_return - turnover * cost_rate
    equity = (1.0 + net_return).cumprod()

    running_peak = equity.cummax()
    drawdown = equity.div(running_peak).sub(1.0)

    mean_return = net_return.mean()
    return_std = net_return.std(ddof=0)
    sharpe = (
        np.sqrt(periods_per_year) * mean_return / return_std
        if return_std > 0
        else float("nan")
    )

    total_return = float(equity.iloc[-1] - 1.0) if len(equity) else float("nan")
    years = len(net_return) / periods_per_year
    annualized_return = (
        float(equity.iloc[-1] ** (1 / years) - 1.0)
        if years > 0 and equity.iloc[-1] > 0
        else float("nan")
    )

    result_frame = pd.DataFrame(
        {
            "close": close_aligned,
            "state": state_aligned,
            "position": position,
            "market_return": market_return,
            "turnover": turnover,
            "gross_return": gross_return,
            "net_return": net_return,
            "equity": equity,
            "drawdown": drawdown,
        }
    )

    metrics = BacktestResult(
        total_return=total_return,
        annualized_return=annualized_return,
        annualized_volatility=float(return_std * np.sqrt(periods_per_year)),
        sharpe_ratio=float(sharpe),
        maximum_drawdown=float(drawdown.min()),
        turnover=float(turnover.sum()),
        trades=int(np.count_nonzero(turnover.to_numpy() > 0)),
    )
    return result_frame, metrics

What this backtest does not model

  • bid–ask spread varying with liquidity
  • market impact and partial fills
  • exchange outages and rejected orders
  • funding on perpetual futures
  • latency between candle close and execution
  • maker/taker fee tiers
  • minimum order size and rounding
  • tax, borrowing and short availability
Do not optimize the threshold directly on final backtest Sharpe and then report the same Sharpe. That is selection bias. Keep an untouched outer test period and include costs during evaluation.

from __future__ import annotations

from numbers import Real

import numpy as np
import pandas as pd
from numba import njit


@njit
def _schmitt_array(
    score: np.ndarray,
    upper: np.ndarray,
    lower: np.ndarray,
    confirmation_bars: int,
    initial_state: int,
) -> np.ndarray:
    output = np.zeros(score.size, dtype=np.int8)
    state = initial_state
    positive_count = 0
    negative_count = 0

    for index in range(score.size):
        value = score[index]
        upper_value = upper[index]
        lower_value = lower[index]

        if np.isnan(value) or np.isnan(upper_value) or np.isnan(lower_value):
            output[index] = state
            continue

        if upper_value <= lower_value:
            output[index] = state
            continue

        if state <= 0:
            if value >= upper_value:
                positive_count += 1
            else:
                positive_count = 0

            if positive_count >= confirmation_bars:
                state = 1
                positive_count = 0
                negative_count = 0

        if state >= 0:
            if value <= lower_value:
                negative_count += 1
            else:
                negative_count = 0

            if negative_count >= confirmation_bars:
                state = -1
                positive_count = 0
                negative_count = 0

        output[index] = state

    return output


@njit
def _long_flat_array(
    score: np.ndarray,
    enter: np.ndarray,
    exit_: np.ndarray,
    confirmation_bars: int,
    initial_state: int,
) -> np.ndarray:
    output = np.zeros(score.size, dtype=np.int8)
    state = initial_state
    enter_count = 0
    exit_count = 0

    for index in range(score.size):
        value = score[index]
        enter_value = enter[index]
        exit_value = exit_[index]

        if np.isnan(value) or np.isnan(enter_value) or np.isnan(exit_value):
            output[index] = state
            continue

        if enter_value <= exit_value:
            output[index] = state
            continue

        if state == 0:
            if value >= enter_value:
                enter_count += 1
            else:
                enter_count = 0

            if enter_count >= confirmation_bars:
                state = 1
                enter_count = 0
                exit_count = 0
        else:
            if value <= exit_value:
                exit_count += 1
            else:
                exit_count = 0

            if exit_count >= confirmation_bars:
                state = 0
                enter_count = 0
                exit_count = 0

        output[index] = state

    return output


def _as_array(
    value: Real | pd.Series,
    index: pd.Index,
    name: str,
) -> np.ndarray:
    if isinstance(value, Real):
        return np.full(len(index), float(value), dtype=np.float64)
    if not isinstance(value, pd.Series):
        raise TypeError(f"{name} must be a number or pandas Series.")
    return value.reindex(index).to_numpy(dtype=np.float64)


def schmitt_state(
    score: pd.Series,
    upper: Real | pd.Series,
    lower: Real | pd.Series,
    confirmation_bars: int = 1,
    initial_state: int = 0,
) -> pd.Series:
    """Convert a noisy score into stable -1/0/+1 states.

    The state switches upward only after the score reaches ``upper`` and
    switches downward only after the score reaches ``lower``. Between the two
    thresholds, the previous state is retained.
    """
    if confirmation_bars < 1:
        raise ValueError("confirmation_bars must be at least 1.")
    if initial_state not in {-1, 0, 1}:
        raise ValueError("initial_state must be -1, 0, or 1.")

    upper_array = _as_array(upper, score.index, "upper")
    lower_array = _as_array(lower, score.index, "lower")
    states = _schmitt_array(
        score.to_numpy(dtype=np.float64),
        upper_array,
        lower_array,
        int(confirmation_bars),
        int(initial_state),
    )
    return pd.Series(states, index=score.index, name="schmitt_state")


def long_flat_hysteresis(
    score: pd.Series,
    enter: Real | pd.Series,
    exit_: Real | pd.Series,
    confirmation_bars: int = 1,
    initial_state: int = 0,
) -> pd.Series:
    """Create a long/flat state with separate entry and exit thresholds."""
    if confirmation_bars < 1:
        raise ValueError("confirmation_bars must be at least 1.")
    if initial_state not in {0, 1}:
        raise ValueError("initial_state must be 0 or 1.")

    enter_array = _as_array(enter, score.index, "enter")
    exit_array = _as_array(exit_, score.index, "exit_")
    states = _long_flat_array(
        score.to_numpy(dtype=np.float64),
        enter_array,
        exit_array,
        int(confirmation_bars),
        int(initial_state),
    )
    return pd.Series(states, index=score.index, name="long_flat_state")

    values[score.isna().to_numpy()] = 0
    return pd.Series(values, index=score.index, name="raw_sign_state")

"""Causal signal generators for hysteresis experiments."""

from __future__ import annotations

import numpy as np
import pandas as pd


def true_range(frame: pd.DataFrame) -> pd.Series:
    """Calculate True Range from OHLC data."""
    previous_close = frame["close"].shift(1)
    components = pd.concat(
        [
            frame["high"] - frame["low"],
            (frame["high"] - previous_close).abs(),
            (frame["low"] - previous_close).abs(),
        ],
        axis=1,
    )
    return components.max(axis=1).rename("true_range")


def atr(frame: pd.DataFrame, period: int = 14) -> pd.Series:
    """Calculate Wilder-style Average True Range."""
    if period < 2:
        raise ValueError("period must be at least 2.")
    return (
        true_range(frame)
        .ewm(alpha=1 / period, adjust=False, min_periods=period)
        .mean()
        .rename(f"atr_{period}")
    )


def rsi(close: pd.Series, period: int = 14) -> pd.Series:
    """Calculate Wilder-style Relative Strength Index."""
    if period < 2:
        raise ValueError("period must be at least 2.")

    change = close.diff()
    gains = change.clip(lower=0)
    losses = -change.clip(upper=0)

    average_gain = gains.ewm(
        alpha=1 / period,
        adjust=False,
        min_periods=period,
    ).mean()
    average_loss = losses.ewm(
        alpha=1 / period,
        adjust=False,
        min_periods=period,
    ).mean()

    relative_strength = average_gain / average_loss.replace(0, np.nan)
    result = 100 - (100 / (1 + relative_strength))
    result = result.where(average_loss != 0, 100.0)
    result = result.where(average_gain != 0, 0.0)
    return result.rename(f"rsi_{period}")


def ma_distance_score(close: pd.Series, window: int) -> pd.Series:
    """Return percentage distance between price and a trailing simple MA."""
    if window < 2:
        raise ValueError("window must be at least 2.")
    moving_average = close.rolling(window=window, min_periods=window).mean()
    score = close.div(moving_average).sub(1.0)
    return score.rename(f"ma_distance_{window}")


def ma_residual_z_score(
    close: pd.Series,
    ma_window: int,
    scale_window: int,
) -> pd.Series:
    """Normalize price-minus-MA residuals by their past rolling deviation."""
    if ma_window < 2 or scale_window < 5:
        raise ValueError("ma_window must be >= 2 and scale_window must be >= 5.")

    moving_average = close.rolling(ma_window, min_periods=ma_window).mean()
    residual = close - moving_average
    residual_scale = (
        residual.shift(1)
        .rolling(scale_window, min_periods=scale_window)
        .std(ddof=0)
    )
    return residual.div(residual_scale.replace(0, np.nan)).rename(
        f"ma_residual_z_{ma_window}_{scale_window}"
    )

def donchian_position_score(frame: pd.DataFrame, window: int = 48) -> pd.Series:
    """Position price inside the prior Donchian range.

    A score above +1 means the close is above the previous channel high.
    A score below -1 means it is below the previous channel low. The channel
    uses ``shift(1)`` so the current candle cannot define its own threshold.
    """
    if window < 2:
        raise ValueError("window must be at least 2.")

    upper = frame["high"].shift(1).rolling(window, min_periods=window).max()
    lower = frame["low"].shift(1).rolling(window, min_periods=window).min()
    midpoint = (upper + lower) / 2
    half_range = (upper - lower) / 2
    score = (frame["close"] - midpoint).div(half_range.replace(0, np.nan))
    return score.rename(f"donchian_position_{window}")


def rsi_reversion_score(close: pd.Series, period: int = 14) -> pd.Series:
    """Create a mean-reversion preference score from RSI.

    Positive values represent an oversold/long preference; negative values
    represent an overbought/short preference. The result lies roughly in
    [-1, +1].
    """
    indicator = rsi(close, period=period)
    return ((50.0 - indicator) / 50.0).rename(f"rsi_reversion_{period}")


def volatility_regime_score(
    close: pd.Series,
    short_window: int = 48,
    baseline_window: int = 1_440,
) -> pd.Series:
    """Compare recent realized volatility with its past rolling median."""
    if short_window < 5 or baseline_window <= short_window:
        raise ValueError("Use short_window >= 5 and baseline_window > short_window.")

    log_return = np.log(close).diff()
    recent_volatility = log_return.rolling(
        short_window,
        min_periods=short_window,
    ).std(ddof=0)
    historical_baseline = (
        recent_volatility.shift(1)
        .rolling(baseline_window, min_periods=baseline_window)
        .median()
    )
    score = recent_volatility.div(historical_baseline.replace(0, np.nan)).sub(1.0)
    return score.rename(f"volatility_regime_{short_window}_{baseline_window}")


def rolling_quantile_band(

        .shift(1)
        .rolling(window, min_periods=window)
        .quantile(quantile)

    )

from __future__ import annotations

from dataclasses import asdict, dataclass

import numpy as np
import pandas as pd


@dataclass(frozen=True)
class SignalQuality:
    """Metrics that describe noise filtering and post-transition behavior."""

    observations: int
    events: int
    raw_flips: int
    filtered_flips: int
    flip_rate_per_1_000: float
    noise_reduction: float
    continuation_hit_rate: float
    median_signed_forward_return: float
    false_reversal_rate: float
    median_run_length: float

    def to_dict(self) -> dict[str, int | float]:
        return asdict(self)


def transition_positions(state: pd.Series) -> np.ndarray:
    """Return integer locations where a non-zero state changes."""
    values = state.to_numpy(dtype=np.int8)
    if values.size < 2:
        return np.array([], dtype=np.int64)

    changed = values[1:] != values[:-1]
    non_zero = values[1:] != 0
    return np.flatnonzero(changed & non_zero) + 1


def count_flips(state: pd.Series) -> int:
    """Count changes between observed states, ignoring leading unknowns."""
    values = state.to_numpy(dtype=np.int8)
    if values.size < 2:
        return 0
    valid = values != 0
    valid_values = values[valid]
    if valid_values.size < 2:
        return 0
    return int(np.count_nonzero(valid_values[1:] != valid_values[:-1]))


def run_lengths(state: pd.Series) -> np.ndarray:
    """Return lengths of consecutive non-zero state runs."""
    values = state.to_numpy(dtype=np.int8)
    values = values[values != 0]
    if values.size == 0:
        return np.array([], dtype=np.int64)

    boundaries = np.flatnonzero(values[1:] != values[:-1]) + 1
    starts = np.concatenate(([0], boundaries))
    ends = np.concatenate((boundaries, [values.size]))
    return ends - starts


def evaluate_signal_quality(
    score: pd.Series,
    filtered_state: pd.Series,
    close: pd.Series,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_move: float = 0.0,
) -> SignalQuality:
    """Evaluate whether filtered transitions are stable and continue.

    Future returns are used only for evaluation. They must never be used to
    construct the score or thresholds.
    """
    if horizon < 1 or reversal_window < 1:
        raise ValueError("horizon and reversal_window must be positive.")

    common_index = score.index.intersection(filtered_state.index).intersection(close.index)
    score_aligned = score.reindex(common_index)
    state_aligned = filtered_state.reindex(common_index).fillna(0).astype(np.int8)
    close_aligned = close.reindex(common_index).astype(float)

    from .triggers import raw_sign_state

    raw_state = raw_sign_state(score_aligned)
    raw_flips = count_flips(raw_state)
    filtered_flips = count_flips(state_aligned)
    events = transition_positions(state_aligned)

    future_return = close_aligned.shift(-horizon).div(close_aligned).sub(1.0)
    valid_events = events[events + horizon < len(close_aligned)]

    if valid_events.size:
        directions = state_aligned.iloc[valid_events].to_numpy(dtype=float)
        signed_returns = directions * future_return.iloc[valid_events].to_numpy(dtype=float)
        finite = np.isfinite(signed_returns)
        signed_returns = signed_returns[finite]
    else:
        signed_returns = np.array([], dtype=float)

    continuation_hit_rate = (
        float(np.mean(signed_returns > minimum_move))
        if signed_returns.size
        else float("nan")
    )
    median_signed_return = (
        float(np.median(signed_returns)) if signed_returns.size else float("nan")
    )

    state_values = state_aligned.to_numpy(dtype=np.int8)
    false_reversals = 0
    reversal_candidates = 0
    for position in events:
        end = min(position + reversal_window + 1, len(state_values))
        if end <= position + 1:
            continue
        reversal_candidates += 1
        direction = state_values[position]
        if np.any((state_values[position + 1 : end] != direction) & (state_values[position + 1 : end] != 0)):
            false_reversals += 1

    false_reversal_rate = (
        false_reversals / reversal_candidates
        if reversal_candidates
        else float("nan")
    )

    lengths = run_lengths(state_aligned)
    median_run_length = float(np.median(lengths)) if lengths.size else float("nan")
    noise_reduction = (
        1.0 - filtered_flips / raw_flips if raw_flips > 0 else 0.0
    )
    flip_rate = 1_000.0 * filtered_flips / max(len(state_aligned), 1)

    return SignalQuality(
        observations=len(state_aligned),
        events=int(events.size),
        raw_flips=raw_flips,
        filtered_flips=filtered_flips,
        flip_rate_per_1_000=float(flip_rate),
        noise_reduction=float(noise_reduction),
        continuation_hit_rate=continuation_hit_rate,
        median_signed_forward_return=median_signed_return,
        false_reversal_rate=float(false_reversal_rate),
        median_run_length=median_run_length,
    )


def bounded_quality_score(
    quality: SignalQuality,
    minimum_events: int,
    maximum_flip_rate_per_1_000: float | None = None,
) -> float:
    """Combine interpretable signal metrics into a bounded Optuna score.

    Hard event-count and optional turnover constraints prevent the optimizer
    from selecting a threshold that simply produces no signals.
    """
    if quality.events < minimum_events:
        shortage = (minimum_events - quality.events) / max(minimum_events, 1)
        return -1.0 - shortage

    if (
        maximum_flip_rate_per_1_000 is not None
        and quality.flip_rate_per_1_000 > maximum_flip_rate_per_1_000
    ):
        excess = (
            quality.flip_rate_per_1_000 / maximum_flip_rate_per_1_000 - 1.0
        )
        return -0.5 - excess

    values = [
        quality.continuation_hit_rate,
        1.0 - quality.false_reversal_rate,
        quality.noise_reduction,
    ]
    if not all(np.isfinite(value) for value in values):
        return -2.0

    return float(
        0.45 * quality.continuation_hit_rate
        + 0.35 * (1.0 - quality.false_reversal_rate)
        + 0.20 * quality.noise_reduction
    )

from __future__ import annotations

from dataclasses import asdict, dataclass

import numpy as np
import optuna
import pandas as pd
from sklearn.model_selection import TimeSeriesSplit

from .metrics import bounded_quality_score, evaluate_signal_quality
from .triggers import schmitt_state


@dataclass(frozen=True)
class FoldResult:
    fold: int
    test_start: pd.Timestamp
    test_end: pd.Timestamp
    upper: float
    lower: float
    confirmation_bars: int
    objective_value: float
    test_events: int
    test_continuation_hit_rate: float
    test_false_reversal_rate: float
    test_noise_reduction: float

    def to_dict(self) -> dict[str, int | float | pd.Timestamp]:
        return asdict(self)


def _search_bounds(score: pd.Series) -> tuple[float, float]:
    finite_abs = score.abs().replace([np.inf, -np.inf], np.nan).dropna()
    if finite_abs.empty:
        raise ValueError("The score has no finite observations.")

    low = float(max(finite_abs.quantile(0.40), 1e-6))
    high = float(finite_abs.quantile(0.995))
    if not np.isfinite(high) or high <= low:
        high = low * 10
    return low, high


def optimize_threshold(
    score: pd.Series,
    close: pd.Series,
    n_trials: int = 80,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_events: int = 20,
    asymmetric: bool = True,
    optimize_confirmation: bool = True,
    inner_splits: int = 3,
    seed: int = 42,
) -> optuna.Study:
    """Optimize thresholds across chronological inner validation folds."""
    index = score.index.intersection(close.index)
    score_aligned = score.reindex(index)
    close_aligned = close.reindex(index)
    valid = score_aligned.notna() & close_aligned.notna()
    score_aligned = score_aligned[valid]
    close_aligned = close_aligned[valid]

    if len(score_aligned) < 500:
        raise ValueError("At least 500 valid rows are recommended for optimization.")

    low, high = _search_bounds(score_aligned)
    splitter = TimeSeriesSplit(n_splits=inner_splits)
    sampler = optuna.samplers.TPESampler(seed=seed)
    study = optuna.create_study(direction="maximize", sampler=sampler)

    def objective(trial: optuna.Trial) -> float:
        upper = trial.suggest_float("upper", low, high, log=True)
        lower_abs = (
            trial.suggest_float("lower_abs", low, high, log=True)
            if asymmetric
            else upper
        )
        confirmation_bars = (
            trial.suggest_int("confirmation_bars", 1, 8)
            if optimize_confirmation
            else 1
        )

        fold_scores: list[float] = []
        for _, validation_positions in splitter.split(score_aligned):
            validation_start = int(validation_positions[0])
            validation_end = int(validation_positions[-1]) + 1

            # Generate state on all data available up to the validation end.
            # This preserves causal state memory at the validation boundary.
            score_context = score_aligned.iloc[:validation_end]
            state_context = schmitt_state(
                score_context,
                upper=upper,
                lower=-lower_abs,
                confirmation_bars=confirmation_bars,
            )

            validation_slice = slice(validation_start, validation_end)
            quality = evaluate_signal_quality(
                score=score_context.iloc[validation_slice],
                filtered_state=state_context.iloc[validation_slice],
                close=close_aligned.iloc[validation_slice],
                horizon=horizon,
                reversal_window=reversal_window,
            )
            fold_scores.append(
                bounded_quality_score(
                    quality,
                    minimum_events=max(3, minimum_events // inner_splits),
                )
            )

        return float(np.mean(fold_scores))

    study.optimize(objective, n_trials=n_trials)
    return study


def walk_forward_optimize(
    score: pd.Series,
    close: pd.Series,
    outer_splits: int = 5,
    n_trials: int = 60,
    horizon: int = 12,
    reversal_window: int = 6,
    minimum_events: int = 20,
    asymmetric: bool = True,
    optimize_confirmation: bool = True,
    seed: int = 42,
) -> tuple[pd.DataFrame, pd.Series]:
    """Tune on past data and evaluate each selected threshold on unseen data."""
    index = score.index.intersection(close.index)
    score_aligned = score.reindex(index)
    close_aligned = close.reindex(index)
    valid = score_aligned.notna() & close_aligned.notna()
    score_aligned = score_aligned[valid]
    close_aligned = close_aligned[valid]

    splitter = TimeSeriesSplit(n_splits=outer_splits)
    out_of_sample_state = pd.Series(
        np.zeros(len(score_aligned), dtype=np.int8),
        index=score_aligned.index,
        name="walk_forward_state",
    )
    fold_results: list[FoldResult] = []

    for fold, (train_positions, test_positions) in enumerate(
        splitter.split(score_aligned),
        start=1,
    ):
        train_end = int(train_positions[-1]) + 1
        test_start = int(test_positions[0])
        test_end = int(test_positions[-1]) + 1

        study = optimize_threshold(
            score=score_aligned.iloc[:train_end],
            close=close_aligned.iloc[:train_end],
            n_trials=n_trials,
            horizon=horizon,
            reversal_window=reversal_window,
            minimum_events=minimum_events,
            asymmetric=asymmetric,
            optimize_confirmation=optimize_confirmation,
            seed=seed + fold,
        )

        params = study.best_params
        upper = float(params["upper"])
        lower_abs = float(params.get("lower_abs", upper))
        confirmation_bars = int(params.get("confirmation_bars", 1))

        # Generate state from the beginning through the test fold so the test
        # state depends only on past observations and keeps boundary memory.
        context_score = score_aligned.iloc[:test_end]
        context_state = schmitt_state(
            context_score,
            upper=upper,
            lower=-lower_abs,
            confirmation_bars=confirmation_bars,
        )
        test_state = context_state.iloc[test_start:test_end]
        out_of_sample_state.iloc[test_start:test_end] = test_state.to_numpy()

        test_quality = evaluate_signal_quality(
            score=score_aligned.iloc[test_start:test_end],
            filtered_state=test_state,
            close=close_aligned.iloc[test_start:test_end],
            horizon=horizon,
            reversal_window=reversal_window,
        )

        fold_results.append(
            FoldResult(
                fold=fold,
                test_start=score_aligned.index[test_start],
                test_end=score_aligned.index[test_end - 1],
                upper=upper,
                lower=-lower_abs,
                confirmation_bars=confirmation_bars,
                objective_value=float(study.best_value),
                test_events=test_quality.events,
                test_continuation_hit_rate=test_quality.continuation_hit_rate,
                test_false_reversal_rate=test_quality.false_reversal_rate,
                test_noise_reduction=test_quality.noise_reduction,
            )
        )

    results_frame = pd.DataFrame(result.to_dict() for result in fold_results)
    return results_frame, out_of_sample_state

from __future__ import annotations

from dataclasses import asdict, dataclass

import numpy as np

@dataclass(frozen=True)
class BacktestResult:
    total_return: float
    annualized_return: float
    annualized_volatility: float
    sharpe_ratio: float
    maximum_drawdown: float
    turnover: float
    trades: int

    def to_dict(self) -> dict[str, int | float]:
        return asdict(self)


def backtest_state(
    close: pd.Series,
    state: pd.Series,
    cost_bps_per_unit_turnover: float = 5.0,
    periods_per_year: int = 365 * 24 * 12,
) -> tuple[pd.DataFrame, BacktestResult]:
    """Evaluate a state using next-bar returns and linear trading costs.

    The position is lagged by one bar. This prevents a signal calculated from
    a candle close from earning the return that ended at that same close.
    This is a research approximation, not an execution simulator.
    """
    if cost_bps_per_unit_turnover < 0:
        raise ValueError("Trading cost cannot be negative.")
    if periods_per_year <= 0:
        raise ValueError("periods_per_year must be positive.")

    index = close.index.intersection(state.index)
    close_aligned = close.reindex(index).astype(float)
    state_aligned = state.reindex(index).fillna(0).astype(float)

    market_return = close_aligned.pct_change().fillna(0.0)
    position = state_aligned.shift(1).fillna(0.0)
    turnover = position.diff().abs().fillna(position.abs())
    cost_rate = cost_bps_per_unit_turnover / 10_000.0

    gross_return = position * market_return
    net_return = gross_return - turnover * cost_rate
    equity = (1.0 + net_return).cumprod()

    running_peak = equity.cummax()
    drawdown = equity.div(running_peak).sub(1.0)

    mean_return = net_return.mean()
    return_std = net_return.std(ddof=0)
    sharpe = (
        np.sqrt(periods_per_year) * mean_return / return_std
        if return_std > 0
        else float("nan")
    )

    total_return = float(equity.iloc[-1] - 1.0) if len(equity) else float("nan")
    years = len(net_return) / periods_per_year
    annualized_return = (
        float(equity.iloc[-1] ** (1 / years) - 1.0)
        if years > 0 and equity.iloc[-1] > 0
        else float("nan")
    )

    result_frame = pd.DataFrame(
        {
            "close": close_aligned,
            "state": state_aligned,
            "position": position,
            "market_return": market_return,
            "turnover": turnover,
            "gross_return": gross_return,
            "net_return": net_return,
            "equity": equity,
            "drawdown": drawdown,
        }
    )

    metrics = BacktestResult(
        total_return=total_return,
        annualized_return=annualized_return,
        annualized_volatility=float(return_std * np.sqrt(periods_per_year)),
        sharpe_ratio=float(sharpe),
        maximum_drawdown=float(drawdown.min()),
        turnover=float(turnover.sum()),
        trades=int(np.count_nonzero(turnover.to_numpy() > 0)),
    )
    return result_frame, metrics
